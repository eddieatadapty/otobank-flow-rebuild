# audiobook.jp Growth Audit

**Live → https://eddieatadapty.github.io/otobank-flow-rebuild/**

Five ideas to turn more audiobook.jp users into subscribers, each built into a clickable version of audiobook.jp's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | The first listen before any account | +10–20% CR to purchase |
| 02 | One question the ad didn’t answer | +5–15% CR to purchase |
| 03 | Your proof where they decide | +5–10% CR to purchase |
| 04 | The year at ¥850 a month | +5–15% CR · ARPU +10–20% |
| 05 | Two real options on ✕ | +5–10% ARPU |

Every price, rating and feature comes from audiobook.jp's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for audiobook.jp. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
